# 台灣沿海船難海污模擬系統 (Taiwan Coastal Shipwreck Marine Oil Spill Simulation System)

> 🌐 **官方正式上線網址（即開即用）**：[https://tsai-py.github.io/taiwan-coastal-spill-simulation/](https://tsai-py.github.io/taiwan-coastal-spill-simulation/)  
> 💻 **Windows 單機免安裝獨立版 (.exe)**：[點此前往 GitHub Releases 下載最新版](https://github.com/Tsai-PY/taiwan-coastal-spill-simulation/releases/tag/v1.0.0)

專為臺灣沿海海域船難應變量身打造之高精度海流現況擴散推演與即時潮位監測系統。

---

## 🌟 系統亮點與功能特色

### 1. 專注標註臺灣五大國際商港（極簡微縮卡片）
* **台北港**（新北市八里區・CWA 測站代碼 `T500023`）
  * 北部貨櫃物流、汽車與石化中樞港。
* **基隆港**（基隆市中正/中山區・CWA 測站代碼 `T001701`）
  * 歷史悠久天然深水良港、亞洲頂級郵輪母港、臺灣高程基準 (TWVD 2001) 起算點。
* **台中港**（臺中市梧棲/清水區・CWA 測站代碼 `T600014`）
  * 臺灣海峽潮差最大商港（潮差近 5 米），離岸風電綠能母港。
* **高雄港**（高雄市旗津/鼓山/前鎮區・CWA 測站代碼 `T401000`）
  * 臺灣第一大國際貨櫃樞紐港，2.4 萬 TEU 超大型貨櫃輪全天候進出。
* **花蓮港**（花蓮縣花蓮市・CWA 測站代碼 `T001501`）
  * 東部直面太平洋天然深水商港，大理石輸出與賞鯨觀光重鎮。

---

### 2. 港旁簡潔標示五大商港地名 (Port Name Labels)
* 地圖商港錨點旁僅精準呈現俐落清爽之商港地名標籤（「**台北港**」、「**基隆港**」、「**台中港**」、「**高雄港**」、「**花蓮港**」），消除繁雜數值，還給海域清爽開闊的視覺空間。
* 點選任意商港標記，即可在右側展開之水文分析抽屜中完整檢視即時潮位數值、24H 天文潮位曲線與進出港水深餘裕評估。

---

### 3. 三大潮位基準面自由切換 (Multi-Datum Support)
1. **海圖基準 (Chart Datum, CD)**：以當地最低低潮位為 $0\text{ cm}$，船舶吃水防擱淺、航海安全最佳基準。
2. **臺灣高程基準 (TWVD 2001)**：以基隆港平均海平面為 $0\text{ cm}$，提供與陸地測量及港灣工程對接。
3. **當地平均海平面 (MSL)**：以各測站多年平均海平面為 $0\text{ cm}$。

---

### 4. 24小時連續天文潮位曲線與水文安全評估
* **24H 動態 SVG 潮位曲線**：呈現今日 00:00 至 24:00 全日潮汐起伏走勢。
* **紅色動態游標**：精準標註當前時間點與即時水位。
* **航海泊靠安全與水深餘裕評估**：依各商港設計水深與當前潮位，實時計算口門安全水深餘裕與進出港建議。
* **中央氣象署未來 30 天官方預報表**：內建彈窗即時查閱 CWA 官方報表。

---

### 5. 依海流現況標示預估汙染擴散範圍及方向 (Ocean Current & Dispersion Engine)
* **左側欄位優先啟動**：系統載入網頁後，**預設優先於螢幕左側直接展開高科技船難海污模擬控制台**，中央海面視野開闊，讓您一邊綜覽臺灣海域地圖、一邊直覺操控推演。
* **🎯 靈活沉船設點：地圖任意點選 ＋ 精確經緯度座標輸入**：
  * **方式 A：地圖海面任意點選**：滑鼠游標常駐十字準星（狀態顯示「🎯 海面點選設置中：就緒」），點擊臺灣海域任一點，沉船標記立即部署並自動同步座標至數值輸入框。
  * **方式 B：精確經緯度數值輸入**：於控制台直接輸入北緯 (Lat °N，18.0~29.0) 與東經 (Lng °E，115.0~126.0) 數值（例：`25.2000` / `121.3200`），按下「`📍 定位`」按鈕或直接於輸入框按下 `Enter` 鍵，地圖自動平滑飛抵該座標並即刻展開流體動力學推演！
  * **智慧防呆校正**：無論點選或輸入之座標若不慎落於陸地範圍，系統皆會智慧將事故點平移修正至最近之鄰近海面上。
* **右側獨立商港水文抽屜**：當點選地圖上的五大商港或頂部港口切換鍵時，右側水文抽屜順暢滑出呈現 24H 連續潮位走勢，與左側海污模擬各自獨立、零重疊干擾。
* **依海流現況即時驅動**：
  * **🌊 周遭海流動態流向箭頭矩陣**：地圖上即時繪製事故海域實時海流向量箭頭（流向角度與流速）。
  * **🧭 預估擴散主方向微型點狀標記**：地圖上以青色微型脈衝光點精確標示擴散軸端點（滑鼠懸停顯示「預估海流擴散主方向: XXX° ｜ 實時流速: X.X 節」），極致輕量不遮擋海面與油膜視野。
  * **⏱️ 擴散推演時間節點標記**：標註 T+3h、T+6h、T+12h、T+24h、T+48h、T+72h 各階段擴散中心點與漂移里程。
  * **海況水文系統耦合**：
    * 東部外海：**太平洋黑潮主流系統**（~020° NNE，1.8~2.3 節強勁北漂）。
    * 臺灣海峽：**海峽狹管天文潮急流**（漲潮 ~030° 湧流 2.2 節；退潮 ~210° 落潮流 1.9 節）。
    * 西南沿海：**黑潮支流與沿岸海流**（漲潮 ~320° 西北流；退潮 ~140° 東南流）。
    * 東北角海域：**陸棚潮流與黑潮支流交匯區**（漲潮 ~065° 東北向；退潮 ~240° 逼近金山萬里岸際）。
  * **⚠️ 三級原油外洩規模**：
    * 輕度外洩：50 噸 (~350 桶，小型漁船/貨輪燃油艙)
    * 中度外洩：300 噸 (~2,100 桶，一般散裝/貨櫃輪油料)
    * 重度海難：1,000 噸 (~7,000 桶，大型油輪/重柴油巨災)
  * **⏱️ 0~72小時時間軸推移與自動動畫播放**：
    * 支援滑桿拖曳與「▶ 播放擴散 / ⏸ 暫停推演」，每 450ms 連續演算流體擴散外推。
  * **🔴 三層級海污擴散多邊形（菲氏擴散定律 Fay's Model，嚴格陸域阻截）**：
    * 🔴 **重度核心油膜區**（厚度 > 1.0mm，深紅黑焦油塊）
    * 🟠 **中度擴散油帶**（厚度 0.1~1.0mm，棕黑乳化油水）
    * 🟡 **輕度油光外圍**（厚度 < 0.1mm，彩虹油光擴散前鋒）
    * 🧭 **潮流漂移向量軸**（流向與流速箭頭標示）
  * **🏖️ 海岸線阻截與岸際油污累計監測（陸域零滲入・遇岸停止並累計）**：
    * **嚴格海岸線幾何阻截**：油膜擴散遇臺灣海岸線立即停止，以 72 道射線緊密貼齊海岸水側邊界，油污多邊形絕不流向陸地。
    * **漂移中心海陸邊界約束**：漂移中心若逼近沿岸自動停止於岸外海面，絕不在陸上漂移。
    * **自訂沉船點防呆校正**：點選地圖若位於陸地，自動平移至最近近海水域。
    * **受污岸際沉積線標示**：地圖即時以高亮紅色脈衝線標示受污海岸段與受污長度（公里）。
    * **累計岸際沉積油量即時計算**：依海浪拍岸與推擠速率，實時動態累計岸際受污公噸數（與總外洩量佔比 %）及海面漂浮殘存量。
    * **沿岸受污行政區與除污指引**：自動辨識受影響縣市岸段，動態發布高潮線陸用吸油棉索與高壓熱水洗石應變指引。
  * **🛡️ 海事應變決策指引**：
    * 提供防污攔油索建議佈設長度（600m / 1,200m / 2,500m）。
    * 提供汲油船（Skimmer）、吸油棉索及近岸化學分散劑禁制作業建議。
    * 預估沿岸拍岸時間（Shoreline Beaching ETA）。

## 🚀 啟動方式

### 方法 A：單機版獨立執行檔（🔥 最推薦・免安裝・原生應用程式視窗）
直接在 `C:\download\` 或專案資料夾中雙擊執行：
```text
台灣沿海船難海污模擬系統.exe
```
* **一鍵秒開**：點擊立即啟動，無黑色命令提示字元 (CMD) 彈跳黑框。
* **獨立桌面視窗**：以專屬應用程式視窗（Edge App Mode）呈現，無瀏覽器分頁標籤與網址列干擾。
* **100% 離線單機**：所有程式碼、樣式、地圖向量圖資與高畫質海事圖標皆已完整嵌入執行檔內，即使單獨將 `.exe` 複製到桌面或隨身碟，在任何 Windows 電腦上都能獨立正常運作！
* **乾淨結束**：關閉應用視窗時自動釋放所有資源並結束背景服務，不佔用系統背景記憶體。

### 方法 B：批次檔一鍵啟動
在 `c:\download\` 資料夾雙擊執行：
```bat
開啟台灣沿海船難海污模擬系統.bat
```
或保留之捷徑：
```bat
開啟台灣環島即時潮位系統.bat
```
即可在預設瀏覽器（Edge / Chrome / Firefox）中開啟！

### 方法 C：Python 本地伺服器模式
在終端機執行：
```powershell
python c:\download\taiwan-ports-tide-system\server.py
```
系統會自動在 `http://localhost:8089` 啟動伺服器並自動為您開啟瀏覽器。

1. 雙擊執行 `c:\download\一鍵前往網站發布.bat`。
2. 瀏覽器會自動開啟 [Netlify Drop](https://app.netlify.com/drop)，檔案總管亦會自動選取已打包好的壓縮檔：
   ```text
   c:\download\taiwan-ports-spill-simulation-release.zip
   ```
3. 用滑鼠將此 ZIP 檔拖入網頁虛線框中，10 秒內即可生成永久公開網址（例如：`https://taiwan-spill-sim.netlify.app`），支援手機與全球各地即時訪問！

### 方法二：GitHub Pages（開源專案標準發布）
本地 Git 儲存庫已完成初始化與 Commit，只需推送到您的 GitHub 帳號：
```powershell
cd c:\download\taiwan-ports-tide-system
git remote add origin https://github.com/<您的GitHub帳號>/<儲存庫名>.git
git branch -M main
git push -u origin main
```
至儲存庫 **Settings ➔ Pages**，將來源設為 `main` 分支即可於 `https://<帳號>.github.io/<儲存庫名>/` 上線。
